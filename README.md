# LoveSick

Four plugins in one installer: **LoveSick** (synth), **efx LoveSick** (effects),
**LoveSick Vocals** (vocal chain) and **LoveSick Loops** (loops and chop pads).

## Download

- **Mac** (Apple Silicon and Intel, VST3 + AU): [LoveSick-Mac.zip](https://github.com/8piecesbck/LoveSick-Downloads/releases/latest/download/LoveSick-Mac.zip)
- **Windows** (VST3): [LoveSick-Windows.zip](https://github.com/8piecesbck/LoveSick-Downloads/releases/latest/download/LoveSick-Windows.zip)

Older versions are on the [Releases](https://github.com/8piecesbck/LoveSick-Downloads/releases) page.

## Install

1. Unzip the download and open the installer inside (`How to install.txt` has the details).
   - Windows: if it says it protected your PC, click **More info**, then **Run anyway**.
   - Mac: if it can't be opened, go to **System Settings > Privacy & Security** and click **Open Anyway**.
2. In FL Studio: **Options > Manage plugins > Find plugins**.

To update, download the newest version and install it over the old one.
